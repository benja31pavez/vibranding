# Client Hub Pro

crea una plataforma que me sirva para las asesorias que le hago a mis clientes, donde pueda tener espacio de lo que son los objetivos a realizar, los entregables, plazos de entrega y además un espacio resumen con estos archivos todo en uno. El espacio resumen debe ser el de un iphone que muestre el perfil de Instagram, con los seguidores, seguidos, foto perfil, descripcion, enlace, y las ultimas 6 publicaciones, la idea es que toda esta data sea editable, ya que yo como diseñador debo de poner mi propuesta de enlace, propuesta de descripcion, propuesta de nueva foto de perfil y propuesta de las 6 publicaciones. Y ademas, cada publicacion debe contar con un caption y la fecha y hora de publicacion. Por ultimo, un espacio para mi para manejar los pagos de mis clientes, asi puedo hacer seguimiento
